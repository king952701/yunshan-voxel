# 云山录 · 体素江湖

3D 体素像素风的沙盒生存制作游戏。无限无缝地图，中式武侠山水：起伏丘陵、层叠山峦、蜿蜒河谷、竹林古松，山谷中散布青瓦飞檐的村落、楼阁、古塔与山寺。

浏览器直接跑，纯前端，无构建步骤，无外部图片/字体/音频资源。

## 运行

```powershell
# 方式一：内置服务器（无需 Python / Node）
powershell -ExecutionPolicy Bypass -File .\start.ps1
# 打开 http://127.0.0.1:8123/

# 方式二：任意静态服务器（VS Code Live Server 等）指向本目录即可
```

> 必须通过 http 打开。ES Module 不能走 `file://` 协议。

## 玩法闭环

1. **采集**：徒手可挖草、泥土、沙、竹叶；木材需斧、石料与矿物需镐，工具不对则极慢且不掉料。
2. **合成**（C，共 50 式，分五类）：
   - 材料加工 15：木/竹板、木棍、木炭、竹纤维、绳索、粗布、青砖、琉璃、灰泥、木梁、竹席、纸窗、粉墙、青瓦
   - 工具兵器 16：冶炼铁锭 + 木/石/铁 三档的 镐·斧·剑·铲·镰（镐采石矿、斧伐木、铲取土沙、镰割草叶）
   - 屋宇营建 9：石碑、火把、灯笼、石灯、飞檐、歇山顶、琉璃瓦、酒旗、牌坊
   - 饮食医药 7：炙肉、炖肉、果脯、清茶、草药膏、金疮药、干粮
   - 护身 3：藤甲（减伤 3）→ 铁甲（6）→ 重铠（9），右键披挂
3. **建造**：右键放置方块自建屋舍。可自制的中式建材有 12 种：青砖、木梁、纸窗、竹席、酒旗、石灯、飞檐、琉璃瓦、木箱、石碑、歇山顶、牌坊；世界改动会写入本地存档。
4. **生存**：饱食度持续下降，归零后掉血；高处坠落受伤；入夜有野兽出没，击杀得生肉。
5. **探索**：地图上随机分布村落、楼阁、五层古塔、山寺与跨河石桥。

## 无缝地图是怎么做到的

- **纯函数地形**：地表高度是 `(世界坐标 + 种子)` 的函数（`generator.js`），所以相邻区块算出的边界完全吻合，不存在接缝。
- **结构溢出写入**：树、竹、房屋、古塔按世界对齐的 cell / region 定位，生成某区块时会把「中心在邻区块、但伸到本区块」的部分一并写入（`structures.js`）。两侧独立计算、结果一致，不会出现半棵树。
- **流式分帧加载**：`world.update()` 每帧按时间预算（约 7 ms）由近及远生成区块，超出视距的区块释放显存。没有加载条、没有卡顿式掉帧。
- **视距自适应**：帧率低于 38 自动收缩视距，高于 55 再逐步放回。
- **顶点级 AO + 面剔除**：只生成可见面，草色按海拔渐变烘焙进顶点色，无需实时阴影也能有层次。

## 可调项

- 种子：`index.html?seed=12345`
- 视距与生成预算：`main.js` 的 `radius` 与 `world.update(..., 7)`
- 昼夜长度：`survival.js` 的 `DAY_LENGTH`（默认 480 秒一天）
- 像素颗粒感：游戏内按 P 切换，或改 `main.js` 的 `pixelScale`
